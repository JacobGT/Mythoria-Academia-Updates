# Mythoria Academia: descargas

Juego para Android de domadores y monstruos.

## Descargar

**[Última versión](https://github.com/JacobGT/Mythoria-Academia-Updates/releases/latest)**: descarga el archivo `.apk`, ábrelo en el móvil y permite *instalar apps de origen desconocido*. Android 7 o superior.

## Actualizaciones

Desde la versión 2.1 el juego comprueba si hay una versión nueva al arrancar:
- Si es una actualización de contenido, se descarga dentro del propio juego.
- Si hace falta un APK nuevo, el juego te avisa de que tienes una versión antigua y te trae aquí.

Tu partida se conserva al actualizar.

`version.json` es el manifiesto que lee el juego. No lo edites a mano: lo publica `tools/publish-update.js`.
